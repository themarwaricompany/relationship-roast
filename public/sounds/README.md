# Sound Effects

This folder contains audio files for the quiz experience.

## Required Sound Files

Each sound should be provided in both `.webm` and `.mp3` formats for browser compatibility:

- `tap.webm` / `tap.mp3` - Button tap sound
- `whoosh.webm` / `whoosh.mp3` - Transition whoosh
- `category.webm` / `category.mp3` - Category change
- `complete.webm` / `complete.mp3` - Quiz completion
- `drumroll.webm` / `drumroll.mp3` - Result drumroll
- `reveal.webm` / `reveal.mp3` - Score reveal
- `verdict.webm` / `verdict.mp3` - Verdict appear
- `share.webm` / `share.mp3` - Share unlock
- `tick.webm` / `tick.mp3` - Form interaction tick sound (NEW)

## Tick Sound Specification

The tick sound should be:
- Very short (50-100ms)
- Soft, subtle "tik" sound
- Low volume (configured at 0.3)
- Similar to a clock tick or keyboard click
- Purpose: Provide feedback during form filling to make user feel something is happening

You can generate these sounds using:
- Free sound libraries (freesound.org, zapsplat.com)
- Text-to-speech or sound generators
- Simple audio editing tools (Audacity, GarageBand)
